## 3. 每个主题的演示设计

### 3.1 随机数如何生成？

**学习契约。** 学生能够用同一种子重现序列，识别短周期，并解释“各区间数量相近”为什么不能单独证明序列质量。只需整数、余数和频数；这些概念在页面内补齐。

**默认实验：一个看得见内部状态的随机数机器。** 使用小模数线性同余生成器（LCG），显示 `种子 → 乘法 → 加法 → 取余 → 新状态 → [0,1) 内的数`。点击单步时，高亮的数依次进入状态环、序列条和直方图；同一数在所有视图中保持一致的标记。

- 首屏控制：生成器预设、种子、生成数量；进阶区可改 a、c、m。
- 预设：`m=16, a=5, c=1, seed=1` 的完整 16 状态周期；只把 a 改为 4，出现迅速陷入重复的反例。以项目已有的固定种子生成器作为较大序列的对照，不称其为密码学随机数。
- 核心证据：当前状态、已走步数、实测重复位置；相邻对 `(uₙ,uₙ₊₁)` 散点展示直方图看不出的结构。有限样本的图形检查不是随机性证明。
- 第二个短实验“把均匀数变成其他分布”：沿离散累积概率条产生骰子结果；再把同一个 u 沿累积分布曲线映射到指数分布 `x=−ln(1−u)/λ`，显示单点路径、密度和累计直方图。可修改离散概率或 λ，实时校验概率合法性。
- 对照与提问：相同种子重启能否得到相同结果？满周期是否就意味着相邻值没有结构？变换 λ 改变的是随机源还是输出分布？
- 计算边界：浏览器内实际整数状态更新和分布变换；教学 PRNG、确定性和可复现性明确标注。数值实现避免大整数乘法舍入、`log(0)` 等边界错误。

知识抽屉解释种子、周期、频率与概率、伪随机与真随机、逆累积分布；延伸阅读包括原 Notebook 与 [NumPy 随机生成器文档](https://numpy.org/doc/stable/reference/random/generator.html)。不沿用“所有 NumPy 随机生成器都是 Mersenne Twister”的旧概括。

### 3.2 随机交换为何产生稳定分布？

**学习契约。** 学生能够逐步核对总量守恒，说明余额非负约束怎样改变分布，并区分“完整微观状态等概率”与“观测量等概率”。不要求统计力学背景。

**默认实验：200 人，每人 10 单位，每次随机选择付款人与收款人，转移 1 单位。** 首次单步放大两人及余额变化，再让这一变化进入排序图与直方图。运行时以明确的“尝试次数”计时，同时列出有效转账数、零余额跳过数和自转账数。

- 首屏控制：是否允许负债、尝试次数、种子；人数和初始均额放在进阶区。
- 对照：两组从相同初态使用相同付款／收款候选序列；只改变负债规则。禁止负债时，付款人余额为零就跳过，不暗中重新选择付款人。
- 图形：身份固定的个体轨迹、按余额排序的整体图、带坐标与计数的直方图；排序时保留选中者的身份，避免误读为同一个人始终最富。
- 关键证据：总余额恒定、平均余额恒定、分布宽度变化；允许负债时可持续展宽，不能把某个时刻近似钟形的直方图称为已达到稳定平衡。
- 第二个短实验“28 个状态”：3 人共享 6 单位且余额非负，将全部 28 个整数状态铺在三角格上。一次转移对应一条状态边；按第一个人的余额汇总节点，得到计数 `7,6,5,4,3,2,1`。直接看见微观状态即使等概率，单人的各余额也不等概率。
- 长期统计：同时显示有限系统的理论边际分布与经验直方图；较大系统才讨论几何分布及连续指数近似。明确近似条件，保留采样波动，不预画“完美平衡曲线”冒充实测。
- 对照与提问：规则公平是否意味着结果相同？哪些数量守恒、哪些量仍会改变？改变一个约束为何改变可访问的状态？
- 计算边界：这是有守恒约束的随机过程；等概率结论针对指定转移规则的平稳分布，单次有限轨迹不等同于平衡证明，也不代表真实经济系统。

知识抽屉从“状态、转移、分布”进入细致平衡与玻尔兹曼类比；熵、系综和遍历性放进进阶内容，并说明适用条件。

### 3.3 随机采样为什么能算积分？

**学习契约。** 学生能够解释单个样本如何进入积分估计，比较投点法与均值法，并通过重复实验观察估计误差。页面内解释面积、平均值和不确定性，不预设积分基础。

**三个可独立打开的小实验：**

1. **投点算 π。** 依次显示 `(x,y) → x²+y² → 是否在四分之一圆内 → 命中计数 → 4H/N`；主图与样本账本同步。
2. **平均高度算面积。** 对 `[0,1]` 上的 `eˣ`，在同图显示投点法和均值法。单步把 `f(x)` 放入累加器，显示 `区间宽度 × 平均高度`。另有正负面积例子，说明均值法不需要函数非负。
3. **双变量曲面下的积分。** 采样位置在平面中标记，函数高度在联动曲面中标记，再进入 `区域面积 × 平均函数值`。这与现有优化页“沿地形找最低点”的任务形成清楚对照。

- 首屏控制：函数例子、估计方法、目标样本数；种子、定义域与“编辑函数”可展开。
- 支持安全表达式编辑 `f(x)` 与 `f(x,y)`、区间／矩形域；复用并扩展现有解析器，不使用 `eval` 或 `new Function`。提交时显示生效与重置说明，预检及采样时都处理非有限值。
- 投点法只用于具有可靠上下界的预设；自定义函数默认用均值法，避免未知峰值越过包围框后产生未提示的偏差。
- 证据：样本数、累计和、当前估计、标准误差及近似区间。预设有已知积分时显示参考值；任意自定义函数没有可靠参考值时，不显示伪造的“真实误差”。
- 重复实验模式：固定 N，用一组可重现的独立随机序列重复实验，展示估计分布和参考值。用 N、4N、16N 比较误差尺度，而非要求单条曲线每步单调改善。
- 计算边界：普通蒙特卡洛在独立同分布、有限方差条件下，标准误差通常按 `1/√N` 缩小；页面中的随时变化区间不能解释为整条轨迹同时有 95% 覆盖率。

默认单次样本数拟定为 1,000；先展示单个样本，再允许批量。最终参数以真实浏览器测得的现象与响应速度校准。

### 3.4 维度升高后，网格为什么算不动？

**学习契约。** 学生能计算张量网格的求值数，按相同求值预算比较方法，并解释蒙特卡洛的误差率为何不等于“高维免费”。先用一维和二维补齐网格、坐标与维度的含义。

**默认实验：** 在 `[0,1]^d` 积分 `exp(−Σxᵢ²)`，从 d=1 逐步提高维度。图形先由点、线、面解释每维加点，再显示 `每维 m 个点 → 总共 mᵈ 次求值`。实际执行与仅估算成本用不同标签，绝不创建不可承受的高维网格。

- 首屏控制：维度 d（拟定 1–12）、总求值预算、函数族。进阶可改定义域、峰的位置／宽度、种子及包含 `x1…xd` 的函数表达式。
- 方法：张量网格中点求积与普通蒙特卡洛。相同总预算比较时，列出各方法实际用掉的求值次数及剩余额度，不能暗中给网格更多计算。
- 图形：预算增长条、重复实验误差分布、误差对求值数曲线。d>3 时显示明确标注的坐标切片或前两维投影与完整数值统计，不用一幅 3D 图冒充高维空间。
- 预设：平滑可分离函数、局部窄峰；前者展示规则网格在低维的优势，后者展示随机采样也可能漏掉重要区域。默认 d=2，学生主动提高维度。
- 证据：函数求值数、维度、实际运行时间和参考误差。解析可分离预设有参考值；自定义函数没有参考值时只报告可计算的估计量与不确定性。
- 对照与提问：每维只取 10 个点，2、4、8、12 维分别需要多少点？相同预算下，误差为什么可能增大？样本数不随维数指数增加，是否意味着方差也不变？
- 计算边界：`mᵈ` 描述这一类张量网格的成本，不代表所有确定性积分方法；蒙特卡洛的方差常数、相对误差和每次求值成本仍可能随维度恶化。

拟定实际求值预算上限为 100,000，批次间让出主线程，支持立即停止。超预算的网格只显示计算规模和原因。

### 3.5 怎样把样本用在重要的地方？

**学习契约。** 学生能解释分层为何减少空缺，说明改变采样分布为何需要权重，并识别“不合适的分布反而增大方差”的反例。页内补齐密度与加权平均的直觉。

**先用可见的低维例子建立因果链：**

- **分层采样：** 同一个函数、同样的求值数，比较全域随机撒点和每个格子内各采一点；高亮每层的局部估计及其体积权重。
- **对偶变量：** 显示一对 `u` 与 `1−u` 的贡献，先在单调函数上观察抵消，再用对称函数展示未必改善。按函数求值数比较，不能把一对算作与一个样本相同成本。
- **重要性采样：** 将 `采样位置 x → 采样密度 q(x) → f(x)/q(x) → 累计估计` 串成可点选步骤。针对双变量峰形函数，使用归一化已知的采样分布及带均匀成分的混合分布，保证整个积分域被覆盖。

**保留原课件的稀有事件案例：** 估计标准正态 `P(Z>5)`。直接抽样往往没有命中；改在尾部按已知分布采样，再逐点显示密度比和贡献。零命中显示“尚未观察到”，不显示“概率确定为零”或零宽置信区间。

- 首屏控制：方法、总求值预算、函数／事件预设；方法特有参数在其说明旁展开，不同时堆出全部算法参数。
- 参数：分层数量、重要性分布位置／宽度、种子；允许编辑低维被积函数。采样密度首版选已知可归一化的家族，不开放任意未经规范化的密度表达式。
- 对照：同一被积函数、同一预算、固定可复现的随机流；显示每次运行改变的因素。重复实验比较经验方差，避免以一次误差碰巧更小判定优劣。
- 反例：采样分布偏离峰值、少数巨大权重、对偶变量在不合适函数上不获益。样本贡献分布与最大贡献就近显示，帮助定位不稳定来源。
- 计算边界：实现的是普通重要性估计，不混入自归一化估计。各方法的误差估计按实际独立单位计算，不能把分层样本、成对样本当作普通独立样本套同一个公式。

延伸阅读包括原 Notebook 与 [Art Owen 的重要性采样章节](https://artowen.su.domains/mc/Ch-var-is.pdf)。完整 VEGAS 与准蒙特卡洛保留为后续可选主题。

### 3.6 模拟的时间怎样前进？

**学习契约。** 学生能够区分物理时间、计算步和播放帧，手工核对一次碰撞时间与速度更新，并指出两类推进方法的适用条件。用两球匀速运动补齐速度和相对运动概念。

**默认实验：同一对弹性硬球的两条模拟轨道。** 左边每隔 Δt 推进后检查接触；右边预测下一次碰撞时刻并直接推进到事件。主时间轴始终对齐相同的物理时刻，而不是对齐计算步数。

- 首屏控制：推进方式／对照、Δt、场景预设；球半径、质量、初始位置和速度可通过图形与数字输入调整。
- 单步计算：`相对位置与速度 → 接触方程 → 合法的最早正时间 → 推进到接触点 → 法向冲量 → 新速度`。每个量与轨迹、法向箭头及读数联动。
- 第二个场景用少量粒子显示未来事件队列：事件时间、参与粒子、有效性；碰撞后划去失效预报并重新计算。可以点选事件观察它为何被保留或丢弃。
- 预设：低速正碰、较大 Δt 造成漏检的高速穿越、斜碰；显示位置差、碰撞次数、总动量与动能。含墙场景不把粒子系统动量误报为守恒。
- 图形用轨迹和时间轴解释方法，动画帧率单独放进播放设置；调慢播放不会改变数值结果。
- 明确“每步末检查重叠”是用于展示离散检测问题的简化基线。加入连续碰撞检测的固定步方法也能避免漏检，不能将基线缺陷推广到所有固定步求解器。
- 计算边界：事件求解基于碰撞间匀速、瞬时弹性碰撞；连续 LJ 相互作用转入下一主题。首版限制为小规模且避免多体同时碰撞；遇到不可可靠处理的并发接触要停下解释，不悄悄任意排序。

交互设计参考 [Princeton 的事件驱动模拟教材](https://algs4.cs.princeton.edu/61event/index.php) 的碰撞预报与失效事件处理。实际计算内核保持小规模、可检查；不引入依赖 Java 的学生运行条件。

### 3.7 从粒子受力到分子运动

**学习契约。** 学生能够根据势能曲线判断吸引与排斥，核对一次位置和速度更新，并用能量证据区分物理交换、外界干预与数值误差。页内补齐向量箭头、动能和势能。

按三个可独立进入的短实验组织，默认打开第一阶段，不要求读完公式才操作。

1. **两粒子的力从哪里来？** 拖动粒子间距 r，联动显示 LJ 势能、局部切线、力箭头和 `F=−dU/dr`；在标准 LJ 势上标出 σ 处势能为零及 `2^(1/6)σ` 的势能最低点。进入截断模型时，曲线、零点与力全部改为实际使用的函数，不沿用未截断势的标记。点击单步，拆开排斥项、吸引项与合力。拖动表示外界操作，显示外界做功；“释放”后才作为自由运动。
2. **一次 Velocity Verlet 更新。** 选中粒子 i，高亮对它贡献的邻居及成对力；依次显示 `旧位置/速度/力 → 新位置 → 重新计算力 → 新速度`，数字带入当前真实状态。每一阶段允许停留，不只在终点刷新粒子。
3. **一盒粒子的集体行为。** 拟定默认 36 个二维 LJ 粒子，在周期边界下运行；联动动能、势能、总能量、温度和速度直方图。选中边缘粒子时出现最小镜像，解释“穿出右边、从左边回来”的实际含义。

- 首屏控制：实验场景、时间步长 Δt、初始温度；粒子数、密度、势参数、种子及边界说明放入进阶区。首版以周期边界为主，避免混入未经验证的墙面处理。
- 参数采用明确的约化单位，并提供单位解释；需要物理量时在抽屉给出氩参数的示例换算，不将二维模型呈现为精确氩模拟。
- 对照预设：同一微观初态、相同物理时长下比较合理 Δt 与过大 Δt；从稳定轨迹执行一次速度缩放，显式记账外界取走的动能，再观察内部能量重新分配。
- 显示 `K`、`U`、`E=K+U`、相对初值的能量变化和物理时间。能量基准接近零时用稳定的尺度衡量漂移，不用会爆炸的相对误差。
- 力与势使用数学一致的截断方案：例如移力势 `Uₛ(r)=U(r)−U(r_c)−(r−r_c)U′(r_c)`，对应 `Fₛ(r)=F(r)−F(r_c)`；超过截断两者为零，明确这修改了原势。周期边长满足最小镜像与截断约束，粒子对只计一次势能。
- 温度以实际自由度计算；去除整体平动时说明其影响。二维平衡速度模分布不套用三维 Maxwell 公式；小系统与相关采样的偏差同时说明。
- 首版不展示未含相互作用维里项的“总压强”，不把一次缩放速度称为正确采样 NVT 的恒温器。冷却后的聚集仅为此模型中的现象，不宣称给出现实物质的熔点或沸点。
- 计算边界：实际经典二维多体数值计算，初态含种子随机性，后续 NVE 推进为确定性更新。数值溢出、严重重叠和不合理步长触发暂停并保留原因。

势函数与温度定义对照 [LAMMPS 的 LJ 文档](https://docs.lammps.org/pair_lj.html) 和 [温度文档](https://docs.lammps.org/compute_temp.html)。不把通用游戏物理引擎作为不可见的计算核心，以保证教学中的力、能量和更新确实对应同一模型。

## 5. UI/UE：延续现有风格，按问题组织画面
