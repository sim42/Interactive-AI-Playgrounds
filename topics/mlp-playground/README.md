## 学习契约（重做后的教学设计）

**核心问题**：两个合成传感器读数经过一张微型网络后，怎样得到一个概率？正确标签与概率的差别，如何经过损失函数、激活函数和连接，成为每个权重的调整量？

**可检验目标**：
1. 沿主图的乘法支路、求和节点、偏置和激活核对一个节点的数值。
2. 根据正确标签选择交叉熵中实际生效的项，解释“给正确类别的概率小”为什么损失大。
3. 沿主图的下游梯度支路、局部导数和 δ，核对每条连接的梯度与更新量；区分节点激活的希望方向和真正更新的权重/偏置。

**最低先修**：乘加与正负数。本页补足特征、标签、概率、损失、梯度和链式法则的直观意义；不要求会微积分或矩阵运算。公式与具体数字放在核心计算图中，每个符号都用中文解释。

**交互因果链**：选择一个样本 → 逐节点计算输入×权重、支路相加、加偏置和激活 → 预测概率与正确标签在同一张图比较 → 展开交叉熵的代入计算 → 从损失向后逐节点相乘并汇总梯度 → 显示每条权重的 δ×上游激活、−学习率×梯度和旧→新变化 → 最后统一提交真实更新。动画是计算状态的逐步展开，连线不采用装饰性闪烁代替数学。

**默认实验与对照**：默认 XOR，种子 42，网络 2→3→2→1，tanh，学习率 0.08。打开默认网络实验台，显示合成数据、每个节点在同一输入平面的响应、权重线与输出区域，以及未训练的实际损失。开始训练后实时观察特征组合；点击“逐步计算检查”看到已准备的首个节点乘加/激活，点击“下一步”检查下一个节点。模式在“学习”和“推理”间切换；推理完全不改参数。直线对照只改结构为 2→1，保留数据、种子、学习率。大步长对照只将学习率改为 5，保留其他默认条件。

**误解与反例**：
- 推理不会自行学习。比较推理一轮前后参数，完全不变。
- 交叉熵不是简单的“预测概率减标签”；p−y 是 sigmoid 与交叉熵合并后的输出 logit 梯度，主图分开显示两者。
- 节点的“希望激活变大/变小”来自负激活梯度，只是局部敏感性；激活不是可独立更新的参数。真正更新权重和偏置。
- 梯度为正时参数应减小；主图同时用箭头方向、长度和数值表达，不能只看颜色。
- 无隐藏层只有直线边界，训练更久不保证能分开 XOR。

**计算性质与边界**：浏览器实际训练的小规模全连接网络；数据是原创带种子合成数据。逐节点动画与图形、概率、损失、梯度、更新量来自同一份参数快照。预览阶段不改参数，最终提交后网络实验台的决策区域与全局指标使用更新后的网络；回看上一计算步骤会明确标注其为本轮旧参数快照。采用逐样本随机梯度下降（SGD），不是 TensorFlow 或真实业务系统。

## 8–15 分钟演示建议

1. 保持默认条件，先预测一条直线能否分开 XOR。开始训练，观察节点内图形与输出边界同步变化，暂停后选择某个节点查看所选样本的实际激活。点击“用当前参数逐步检查”，明确建立新快照。
2. 用“下一步”观察每一个前向节点。读出两条/三条乘积支路，求和并加偏置，检查激活后的值。可以点击其他节点或连接聚焦。
3. 到达损失阶段，对照概率条与标签，指出交叉熵的哪一项为零、哪一项实际生效。观察正确类别概率 q 与 −ln(q) 的对应曲线。
4. 输出节点反向：观察 dL/da 乘 sigmoid 局部导数得到 δ，并核对 δ=p−y。
5. 隐藏节点反向：观察从各个下游节点返回的“连接权重×下游 δ”先相加，再乘本节点激活导数；连接梯度为 δ×上游激活，偏置梯度为 δ。
6. 更新预览：逐节点检查所有输入连接和偏置的旧→新条形，说明正梯度为何使参数减小。最后一步统一提交，观察该样本损失前后与整体验证指标。
7. 切到推理重新走一轮，核对权重未变。再做连续训练，观察训练/验证损失、类别区域和各隐藏节点的二维激活图；暂停后用当前参数开始新一轮检查。
8. 选择直线结构对照，保持其他配置，观察 XOR 的表示能力限制。若改变多个条件，应列出变化，不能当成单因素因果实验。

## 参数、数据与算法说明

- 4 组人工二分类：线性分界、XOR、内外环、双月牙；输入为无量纲合成读数，范围固定 −1.2 至 1.2。
- 训练 120 点、验证 60 点；分别生成且验证不参与参数更新。课堂用验证集比较配置后，不称为独立测试集。数据生成、模型初始化和训练顺序使用独立的带种子随机流。
- 网络结构选项：2→1、2→3→1、2→3→2→1、2→4→3→1、2→6→4→3→1。默认微型结构使每条连接可逐步检查。
- tanh 输出在 −1 至 1，局部导数 1−a²，接近两端时梯度变弱。ReLU 把负加权和置零，正区间导数 1、负区间导数 0，在零点采用 0 的约定。
- 输出始终 sigmoid，p 表示类别 1 概率。稳定交叉熵 L=softplus(z)−yz，训练直接使用稳定的输出 δ=p−y；极端 dL/dp 仅显示其方向和量级，不用不稳定的概率导数乘积计算更新。
- SGD 每看一个训练样本就按负梯度更新参数。学习率 η 范围 0.001–5。连续训练一个 epoch 使用每个训练样本一次、确定性打乱顺序；最大 600 epoch，按短批次让出主线程。
- 参数、结构、数据变化立即取消旧过程并重新初始化。重新开始保留配置；重置恢复默认；换数据显式增加种子并清空训练。
- 单样本学习只有最终提交改变网络；上一/下一步可回看本轮快照，不重复提交。新一轮用当前参数重新计算。
- 明确失败案例：XOR、2→6→4→3→1、ReLU、学习率 5、种子 107，单步最多 3 epoch 会触发实际的数值过大保护。失败计算不提交，保留最近有效参数并提示减小步长；不是所有大步长条件都会发散。
