# 维度升高后，网格为什么算不动？

## 学习契约（编码前确定）

- 核心问题：维度升高后，网格为什么算不动？
- 学习目标：计算 mᵈ 的张量网格成本；同求值预算比较方法；解释高维中方差、相对误差与单次成本的变化。
- 最低先修：会读坐标和求平均即可。页面补充积分、概率密度、标准误差等直觉，公式在知识手册逐层展开。
- 交互因果链：改变维度和预算 → 求最大可容纳网格 → 实际求值／随机样本 → 展示估计与有限预算证据。
- 默认与对照：默认 d=2，预算 1,000，种子 42；exp(−Σxᵢ²)。对照局部窄峰及自定义 x1…xd。
- 常见误解与反例：普通蒙特卡洛的 1/√N 率不表示高维免费；二维显示明确是切片和前两维投影。
- 实现性质：浏览器中实际执行的小规模数值实验，合成函数与种子伪随机样本；不是统计规律的证明。模型与图形、指标共用同一状态。

## 运行

整个目录复制到任意路径，双击 index.html。无需安装、网络或服务器。所有依赖位于目录内部；外部阅读仅主动点击后联网。
