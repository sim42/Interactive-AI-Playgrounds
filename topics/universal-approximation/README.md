# 通用近似：从一条折线到神经网络曲面

完整复制本目录，双击 `index.html` 即可离线使用。建议演示 12–18 分钟；三个阶段也可分别使用。

## 新学习契约（2026-10-09 重做）

1. **核心问题**：连续曲线怎样由简单的拐角单元组合出来？一维的确定构造如何帮助理解二元函数的网络逼近，以及“能够表达”和“训练成功”的差别？
2. **学习目标**：改变采样点数，观察相邻割线形成的折线误差；逐单元解释 ReLU 的拐点与斜率变化，核对重建与插值完全一致；改变二元网络的隐藏层数、宽度和训练样本数，比较真实预测与验证误差，并陈述定理的范围。
3. **最低先修**：能读坐标、比较数值即可。页面补足采样点、割线、斜率、折线、ReLU、隐藏层和误差的直观含义；公式放在对应计算旁，无需微积分。
4. **因果链**：阶段 1 改函数/采样数 → 在 `[-1,1]` 等距采样 → 用相邻割线插值 → 显示目标、点与误差。阶段 2 保持这些点 → 从相邻斜率差计算 ReLU 权重 → 一次加入一个单元 → 主图同步显示单元贡献、拐点与累加曲线。阶段 3 改二元目标/点数/深度/宽度 → 重新生成训练样本并初始化网络 → 全批量反向传播与 Adam 更新 → 同尺度目标/预测与独立验证指标变化。
5. **默认实验与对照**：一维默认 `sin(pi*x)+0.25*x`，9 个等距点；改为 3 点、17 点只改变采样密度。二元默认碗形 `0.65*(x^2+y^2)-0.6`，225 个训练点，1 个隐藏层、宽度 32、tanh、Adam 学习率 0.01、种子 20261009。深度和宽度的对照每次只改一个参数，保留函数、样本和种子；不同形状的网络初始化维度不同，不能声称所有初始权重完全相同。
6. **误解与反例**：单层在本页指一个隐藏层，不是只有输出层。ReLU 可以精确重建任意指定的一维折线，但有限点的折线不等于精确重建整个连续目标；3 点可能漏掉起伏。均匀加密对紧致域上的连续函数提供逼近方向，不包括任意不连续函数的一致逼近。增加宽度/深度不保证本次 Adam 找到最佳参数。线性激活仍只能输出仿射平面。
7. **实现性质与边界**：阶段 1 是实际采样与分段线性插值；阶段 2 是确定参数的真实单隐藏层 ReLU 前向计算，不运行梯度训练；阶段 3 是浏览器中真实训练的单/多隐藏层 MLP。所有函数和数据均是合成案例。验证样本不参与梯度更新、自动择优或提前停止；用户根据验证结果调参后，验证误差不能称独立测试误差。

## 实际算法

### 一维插值与 ReLU 构造

域 `[-1,1]`；采样数 3–40（含端点），点按 x 排序且严格递增。相邻斜率为 `sᵢ=(f(xᵢ₊₁)−f(xᵢ))/(xᵢ₊₁−xᵢ)`。插值折线为：

`p(x)=c+s₀x+Σᵢ₌₁ⁿ⁻²(sᵢ−sᵢ₋₁)ReLU(x−xᵢ)`，`c=f(x₀)−s₀x₀`。

直线通路实际使用 `s₀ReLU(x)−s₀ReLU(−x)`，因此全部非恒定项都是一个隐藏层的 ReLU 单元；c 是输出偏置。构造共有 n 个隐藏单元（2 个直线通路单元与 n−2 个内部结点单元），系数为零的单元仍显示其“斜率不变”。不是预置动画：播放索引决定真实前向求和中采用了哪些单元。

连续函数在紧致区间上一致连续，均匀网格间距趋于零时，相邻端点的分段线性插值可一致逼近。页面仅显示有限采样实验，误差指标是在 801 个稠密观察点上的最大绝对误差，不称整个区间误差的严格上界。函数编辑器不自动证明用户函数的连续性；语法合法、有限取值也不等于全域连续。

### 二元回归

域 `[-1,1]²`，无量纲。训练点数 25–900，由带种子的二维分层采样生成；独立验证集为 21×21 网格（441 点），不与训练坐标重合。训练样本数改变时，数据与本轮训练重新建立，种子不变。

隐藏层数 1–3，各隐藏层共用所选宽度 1–48；激活 tanh/ReLU/线性，输出层线性。所有层的权重和偏置实际训练。损失为训练点上的均方误差，显示 RMSE（平方根）；一次更新是全部训练样本的一次 epoch。Adam β₁=0.9、β₂=0.999、ε=10⁻⁸；最多 2000 次更新。运算分批让出主线程，大网络自动减少每个画面间隔中的更新数，单次参数更新不依赖帧率。

曲面采用 CPU Canvas 2D 绘制固定视角的 3D；绘图采样为 21×21 位置，有限网格可能漏掉更密的起伏。目标与预测共用由目标训练/验证/33×33 绘图检查位置取值确定并记录的响应范围，训练时超出范围会提示截断；基准对照采用两次目标观察范围的并集，数值指标仍保留原值。热图、3D 和读数从同一模型状态计算。验证最大误差只统计网格；不声称是整个连续域的一致误差上界。

## 函数编辑与状态

安全表达式解析器支持 `+ - * / ^`、括号、`sin/cos/tanh/exp/log/sqrt/abs` 和 `pi/e`；不使用 eval 或动态代码执行。阶段 1 仅允许变量 x，阶段 3 允许 x、y。应用前检查语法与本实验采样/绘图位置的有限取值；错误就近显示并保留上一组有效结果。复杂定义域或未采样位置仍可能有问题，不把数值检查声称为连续性证明。

重置实验恢复三个阶段的默认配置；阶段 2“重新拼接”保留函数、采样点和当前单元参数（包括手动改动），将加入单元归零；“恢复精确折线构造”恢复由割线斜率确定的原权重/拐点并显示完整和；阶段 3“重新开始”保留参数与种子重新初始化；“换一组训练点”仅显式更改数据种子并重启。切换阶段自动暂停当前动画/训练，同一时刻只运行一个循环。隐藏页面也暂停。
