# 从粒子受力到分子运动

## 学习契约

- 核心问题：一条势能曲线怎样变成一盒粒子的运动，又怎样判断运动算得可信？
- 学习目标：从势能斜率判断吸引与排斥；核对一次 Velocity Verlet 的位置、力和速度；用能量账本区分内部交换、外界做功与数值漂移。
- 最低先修：距离、速度、加减乘除。力箭头解释方向，动能是运动的能量，势能描述相对位置；公式按计算阶段展开。
- 因果链：改变粒子间距／时间步／初始温度 → 受力或积分更新改变 → 力箭头、轨迹、K/U/E/T 与速度分布变化 → 用同一计算状态解释观察。
- 默认实验：两粒子 Lennard–Jones 势，拖动间距联动势能曲线和局部切线。第二实验逐项核对 Verlet；第三实验为 36 个二维粒子周期盒。
- 对照：同一微观初态、相同物理时长，用合理和过大时间步比较能量漂移；一次速度缩放后记录外界取走的动能，再观察 K 与 U 交换。
- 误解与反例：画面流畅不保证积分准确；总能量守恒并不意味着每个粒子的速度或总动能不变；一次速度缩放不是正确采样 NVT 的恒温器。
- 实现性质：实际经典二维多体计算，约化单位；初态含固定种子随机性，后续无外界干预时为确定性 NVE 更新。采用数学一致的移力截断势、最小镜像、每对粒子只计一次势能。不是精确氩模型，不预测现实熔沸点，不展示遗漏维里项的“总压强”。

## 运行与演示

完整复制本目录，双击 `index.html`。全部核心资源在本地；外部知识链接为可选主动访问。

1. 拖动第二粒子或键入间距，观察实际移力势的曲线与力方向；进阶选项可切换标准 LJ 势，核对σ处的零点。
2. 切换“逐步更新”，逐步完成旧状态 → 新位置 → 新力 → 新速度，所有读数来自实际模型。
3. 进入“一盒粒子”，运行并暂停，点击粒子查看邻居和最小镜像。
4. 从相同初态比较 Δt，或执行一次冷却，解释能量与外界取热账本。

约化单位：长度以 σ、能量以固定基准 ε₀、质量以 m、时间以 √(mσ²/ε₀) 为单位，kB=1。去掉整体平动后自由度为 2N−2，T=2K/(2N−2)。二维平衡速率参考为 Rayleigh 形式，仅在近似平衡时有解释意义。


## 预设与数值边界

默认两粒子间距1.5σ、静止释放、Δt=0.004、移力截断rc=2.5σ。盒内默认36粒子、密度0.35、初温0.6、种子2026；ε参数改变势阱深度，不重新定义能量单位。每轮上限5000个完整物理步。严重近距、非有限量或能量偏差超过初态尺度50%会暂停，并要求调整后重启。

Δt对照从当前参数与种子重新生成相同初态，计算100步与200个半步，比较相同物理时长；不会从主实验的中间状态继续。最小可用步长0.0005，因此对照入口要求当前Δt至少0.001。
