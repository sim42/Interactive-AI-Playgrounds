# 模拟的时间怎样前进？

## 学习契约

- 核心问题：每隔一段时间检查一次，是否一定能看见两球相撞？
- 学习目标：区分物理时间、计算步和播放帧；代入一组数核对碰撞时刻与新速度；解释事件预报何时失效及两类方法的适用边界。
- 最低先修：知道位置和速度的含义即可。页面用距离箭头、相对速度和逐步账本补齐平方、法向量与动量。
- 因果链：改变时间步／球的初态 → 改变检测时刻或预报 → 同一物理时刻的轨迹、碰撞次数与位置差变化 → 解释漏检。
- 默认实验：相向运动的等质量两球，固定步与事件轨道从完全相同的初态开始。对照实验仅增大 Δt；高速穿越预设展示末端重叠检测的漏检。斜碰及三球场景用于冲量与失效预报。
- 误解与反例：末端检查遗漏碰撞不代表所有固定步算法都会漏检；含连续碰撞检测的固定步方法可以解决此问题。碰撞间匀速才适合此处事件模型，不能直接用于连续 Lennard–Jones 力。
- 实现性质：浏览器实际求解二维弹性硬球。固定步轨道是简化的“推进后检查重叠”基线；事件轨道求接触方程最早合法根，维护带版本的预报。无墙开放场景，粒子总动量与动能守恒可核对；不支持多体同时接触，检测后暂停解释。

## 运行与演示

完整复制本目录，双击 `index.html`；无需联网、安装或本地服务器。知识手册中的外部阅读仅在主动点击时联网。

1. 默认点击“下一计算阶段”，读相对运动、接触方程、接触时刻和法向冲量。
2. 点击“推进一个时间步”比较相同物理时刻的两条轨道。
3. 切换“高速穿越”，检查固定步漏检时动能虽没变但轨迹已错的反例。
4. 切换“三球接力”，点击预报记录，核对为何旧事件因参与粒子速度改变而失效。
5. 修改参数会重新开始；“重新开始”保留当前参数，“重置实验”恢复全部默认。

初态为明确预置的合成数据，无随机数据来源；种子仅用于“换一组初态”生成可重复的扰动。默认半径0.55、质量1，位置(2,3)/(8,3)，速度(1,0)/(−1,0)，Δt=0.5，种子42；高速场景速度±5、Δt=1。
