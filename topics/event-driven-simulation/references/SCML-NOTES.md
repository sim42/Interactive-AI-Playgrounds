# 原课件与本地改写

来源：sim42/SCML，提交 f07e5016bd2dc55c6c5a6842c46a39b027e50f1e，研究日期2026-10-16。

三种时间不要混淆：物理时间描述模拟世界；固定时间步决定何时检查；播放帧只决定画面何时显示。改变播放速度不改变物理结果。

事件驱动提前预报：硬球碰撞之间匀速，因此能解出接触时刻，直接推进到事件，再改变速度。连续受力时不能直接套用这种匀速预报。

预报也有失效日期：一个球先与别人相撞，原来的速度不再有效。事件保存粒子版本，取出时核对；失效事件必须跳过。

固定步基线的边界：本页只在每步末检查重叠，用来展示延迟或漏碰撞；加入连续碰撞检测的固定步方法也可避免穿越。

守恒不是唯一验收：漏掉碰撞时速度可能完全不变，动能仍可守恒。因此还要检查碰撞次数、时刻和轨迹。共享粒子的同时接触会明确停止。
