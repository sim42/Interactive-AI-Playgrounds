# 怎样把样本用在重要的地方？

## 学习契约（编码前确定）

- 核心问题：怎样把样本用在重要的地方？
- 学习目标：解释分层与成对采样；逐点核对密度与权重；通过重复实验识别差的采样分布。
- 最低先修：会读坐标和求平均即可。页面补充积分、概率密度、标准误差等直觉，公式在知识手册逐层展开。
- 交互因果链：改变采样方法或分布 → 位置和采样密度变化 → 权重／成对贡献 → 同预算估计及重复实验方差。
- 默认与对照：默认 eˣ 对偶变量，预算 1,000，种子 42；对照对称函数、二维窄峰及 P(Z>5)。
- 常见误解与反例：对偶变量未必获益；偏离峰值的密度可产生巨大权重；零命中不代表概率为零。
- 实现性质：浏览器中实际执行的小规模数值实验，合成函数与种子伪随机样本；不是统计规律的证明。模型与图形、指标共用同一状态。

## 运行

整个目录复制到任意路径，双击 index.html。无需安装、网络或服务器。所有依赖位于目录内部；外部阅读仅主动点击后联网。

## 教师演示

先预测一次样本的贡献，点击“单步”四次核对采样、求值、累加与估计，再批量运行，最后只改变一个条件做对照。打开知识手册会暂停实验。重新开始保留当前参数与种子；恢复默认重置全部条件。
