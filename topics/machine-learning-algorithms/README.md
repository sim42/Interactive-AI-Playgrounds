# 简单机器学习：从一次乘加到分类和分组

## 本轮学习契约

- 核心问题：算法究竟根据哪些数作判断，又改变了哪些数？
- 可检验目标：用数据计算线性SVM得分、间隔、hinge损失和一次次梯度更新；按距离排序与逐票计数解释kNN；按距离最小和坐标均值解释k-means。
- 最低先修：乘加、平方、平均数。页面解释特征、标签、权重、偏置、距离、梯度与预测，不要求编程或微积分。
- 因果链：选择算法与例子→读取高亮样本→在主运算图上看输入、运算节点和输出→提交真实状态变化→图形与指标同步；每一动作都对应模型state，不用线条闪动代替数学过程。
- 默认与对照：SVM、可分双团、种子42、η=0.08、λ=0.04；仅改数据为XOR，观察直线限制。kNN保持同数据可检查距离/奇数k投票；k-means不使用标签，改变中心数会改变分组。
- 误解与反例：分类正确但间隔不足1仍产生hinge损失；更多邻居不保证更正确；更多簇降低平方距离但不代表更多真实类别。
- 性质与边界：实际线性软间隔SVM逐样本次梯度、欧氏kNN、Lloyd聚类；无核方法、无真实工程数据。有限优化不保证精确最优。数学计算图直接读取同一份状态，文本记录仅作辅助。

## 操作与课堂路径

完整复制或解压主题目录后双击index.html，现代浏览器直接以file://离线运行，无需安装或服务器。

1. 先读算法说明与问题；点击“下一步计算”。
2. SVM的四动作依次是选样本、乘加/间隔/hinge、正则与数据次梯度、参数旧值与新值。主图展示每一个数的去向；数据图高亮同一编号。
3. 用“播放计算”连续推进，可暂停。快进一轮只跳过展示时间，不改变算法。
4. 选择kNN看坐标差→平方→加和→开根号，再排序和逐票累积；修改查询点仅重做推理。
5. 选择k-means看点到各中心距离的共尺度条形比较；更新中心时看坐标和→除以点数→新中心。
6. 改参数会停止旧任务并重新开始；重新开始保留配置，重置恢复默认，换数据递增种子。

## 计算定义与参数提示

默认24训练点、12验证点；不同随机流生成。SVM只用训练点；验证集不参与梯度或预处理，只用于课堂观察，调参后不称独立测试集。人工特征固定范围[-2.5,2.5]，并非利用验证集拟合的标准化。

SVM目标为 λ/2‖w‖² + 平均max(0,1−yf)。m<1时g(w)=λw−yx，g(b)=−y；否则只有权重正则。m=1采用数据次梯度0。η范围0.005–0.5，λ范围0–1；12epoch=288次参数更新，每次4动作。次梯度可在非光滑折点使用。参数非有限或绝对值达到1e5会停止。

kNN欧氏距离，k=1–15的奇数、等权多数票；距离相同按编号稳定排序。推理不学习权重。k-means用全部36点但不读标签，中心2–5个；空簇保留原中心，最多12轮或中心最大位移<1e-5。

所有随机数据与初始化可由种子1–999999重现；绘图不消耗随机数，播放间隔80–1800ms只改变观看速度。源码按model/view/app分离，传统脚本；不依赖网络、存储或GPU。来源为原创说明与本地references.md中的核对记录，运行资源采用本地D3与KaTeX，来源与许可见THIRD_PARTY.md。

## 2026-10-10：参考同类项目后的设计契约

本轮核心问题是“只移动或改标签的一个训练点，算法哪一步、哪条边界会改变？”借鉴Kanaries的点编辑/查询/阶段控制，以及Naftali Harris的最近中心区域和交替分配/均值更新。保留实际逐步数学，将实验区改为数据平面与相邻运算检查；D3负责坐标、等高区域、点选择和拖动，KaTeX呈现对应公式。

学生能选择/拖动训练点，也能用编号、坐标和标签表单完成相同操作；应用时停止旧循环并清空受数据影响的全部计算。修改是可复现配置的一部分，重新开始保留编辑，恢复生成数据/换种子/换例子清除编辑。验证点保持原始独立数据，不能编辑；聚类使用全部点但仍不读标签。

默认数据/种子/算法不变，对照只改变一个训练点或其标签。预期误解反例：局部数据变化可改变kNN投票或SVM梯度，不能仅凭一次准确率把编辑的数据称为真实测量；k-means淡色区域表示当前最近中心，不冒充已执行完的点分配。
