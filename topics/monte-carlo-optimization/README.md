# 随机搜索与模拟退火：看见随机提议与接受检验

本主题演示寻找较低目标值的随机优化；蒙特卡洛积分则聚合样本贡献来估计总量，两者使用不同指标。保留原目录 `monte-carlo-optimization` 以兼容已有书签。

## 学习契约（先于本次重做实现写定）

- 核心问题：随机候选怎样变成优化，为什么有时要接受更差的位置？
- 学习目标：从带种子随机数核对候选点的生成；计算候选差值、退火接受概率，并在概率尺上比较随机数；保持种子等条件不变比较零温度和正温度，并区分当前点与历史最好。
- 最低先修：横纵坐标、加减乘除。本页解释函数值、均匀随机数、概率与温度；不要求学生写程序。
- 交互因果链：改函数、算法或数值 → 清空旧轮状态 → 单步展开真实运算 → 候选虚线/向量出现 → 提交后轨迹与函数值曲线同步变化。
- 默认实验：波纹 0.3*(x^2+y^2)+2*sin(1.5*x)^2+2*sin(1.5*y)^2；模拟退火；步幅 0.55；初温 1.2；冷却 0.99；起点 (2.3,1.8)；种子 42；域 [-3,3]²；提议上限 500。
- 对照：默认和对照按钮只改变注明的条件；重新开始保留全部当前条件，重置实验恢复默认。
- 常见误解：当前点可能暂时变差，但历史最好保留；退火接受更差候选不表示历史最好变差，随机搜索也不保证找到最优。
- 实现性质：浏览器实际计算用户给出的二元标量函数、优化更新与候选检验；3D 图是 CPU 采样绘图，未运行真实训练任务。

## 独立运行

完整复制本目录，双击 `index.html`（`file://`）。无安装、账号、网络或项目外依赖。函数输入支持显式乘号、`+ - * / ^`、括号、`sin cos tanh exp log sqrt abs`、`pi e`；示例 `sin(x)*cos(y)+0.1*(x^2+y^2)`。最多 240 字符、120 个运算节点；禁止任意 JavaScript。函数需在选择的矩形域网格和起点上产生有限值；此检查不能证明域内每一点均有效，运行中的非法候选仍有明确反馈。函数值跨度或优化器记忆溢出时会提示缩放函数，不能用非有限数值继续绘图或更新。

2. 点击“下一计算阶段”，逐项看运算框及连接箭头；尚未提交的候选为黑色 ×，当前点为橙色圆。

## 算法、数据与边界

随机数为固定种子的 LCG；每次提议固定消耗三个数。全域搜索 x=min+(max−min)r₁、y同理；局部爬山/退火 Δx=σ(2r₁−1)、Δy=σ(2r₂−1)，即方形均匀邻域。候选不更差时 p=1；更差候选仅退火以 exp(−Δf/T) 接受。T=0 不接受更差候选，冷却为 T=T₀cᵏ，p 不溢出；域外或非法函数值候选 p=0。当前点与历史最好独立记录，没有全局最优保证。

原始函数值允许正、零、负。3D 高度、颜色和俯视等高线使用同一网格与已知轨迹联合范围的线性标尺；历史纵轴自动扩展并标注范围。显示网格近似函数，不是优化算法。路径和运算使用真实坐标与值。自定义函数可非凸、非光滑；本课件不证明优化收敛，也不能验证所有表达式的连续性。

## 教师提示

建议 10–15 分钟：默认逐步 3 分钟 → 一因素对照 4 分钟 → 自定义函数与失败例 3 分钟 → 解释 2 分钟。先让学生计算一个分量/概率再继续；不要只比较最终曲线。随机演示必须保持种子才能形成公平对照。

### 本轮使用方法

1. 点击“连续完成 20 次”观察真实轨迹，再点击“冻结本轮为 A”。A 为已提交历史的独立副本，B 自动回到原始起点。

3. “恢复 A 条件”验证重现；“清除 A”仅清除对照。修改函数、域、起点或随机种子时主动清除 A，避免混用问题。只换算法/优化参数时保留 A，并列出所有差异；多个变化明确注明。
4. “下一计算阶段”展开单次数学；面板自身也有下一阶段按钮，可就近核对，不必反复寻找左侧按钮。
