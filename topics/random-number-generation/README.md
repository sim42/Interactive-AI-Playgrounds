# 随机数如何生成？

## 学习契约
- 核心问题：确定的程序怎样产生看似随机的数，又怎样改变这些数的分布？
- 目标：用同一种子重现序列；从周期及相邻数散点识别一个失败生成器；根据累积概率解释一次离散或指数分布采样。
- 先修：整数、余数和频数。页内解释种子、取余、概率与累积概率，无需编程。
- 因果链：修改乘数或种子 → 真实整数更新 → 状态环/相邻数点/直方图；修改分布参数 → 同一均匀数的映射改变 → 输出分布改变。
- 默认实验：LCG a=5,c=1,m=16,seed=1 的16状态周期；对照仅改a=4陷入固定点。较大序列用项目已有Mulberry32教学生成器。
- 误解与反例：满周期不意味着相邻数独立；直方图均匀不意味着适合安全应用。λ改变分布而非均匀随机源。
- 实现性质：浏览器内实际整数状态更新及逆累积分布变换。生成器均是可复现的教学伪随机数，不用于密码学。

## 运行与演示
将整个目录复制到任意位置，双击index.html。无需安装或联网。先点击“单步计算”跟踪乘法、加法、取余和输出；再运行一段序列。切换短周期预设对照。第二个标签用同一均匀数映射离散事件或指数变量。

“重新开始”保留参数及种子；“重置实验”恢复默认；参数改变明确清空旧样本。动画速度只影响展示，样本序列不变。打开知识手册会暂停。

## 数值与数据边界
合成数据，LCG小模数用于看清状态结构，Mulberry32仅作较大教学序列对照。样本直方图与散点不构成随机性证明。指数变换输入严格位于[0,1)，离散概率必须非负且和为1；不自动暗中归一化。动态画幅变化在图中注明。
