# 随机交换为何产生不同分布？

## 学习契约
- 核心问题：对称的随机转移为什么不会让每个人拥有相同余额？
- 目标：核对单次交换的总量守恒；比较允许负债和禁止负债的可访问状态；用28状态枚举解释微观等概率不等于单人余额等概率。
- 先修：加减法、平均数和频数，页面用资金交换补足“状态”和“转移”的直觉。
- 因果链：同候选转账改变余额 → 固定身份轨迹和排序图 → 直方图；仅改变负债约束，候选序列和初态不变。
- 默认实验：200人，每人10单位，种子42，目标100000次尝试；两种规则使用同一候选付款/收款序列。第二实验为3人共享6单位、初态(2,2,2)，种子42。
- 误解与反例：允许负债的宽度可持续增加，不存在有限的平稳余额分布；禁止负债时，付款人无钱就跳过，重新抽付款人会改变过程；同余额可对应不同数量的完整状态。
- 实现性质：实际模拟守恒随机交换和精确枚举，不是现实经济模型，有限轨迹不证明达到平衡。

## 运行与演示
将整个目录复制后双击index.html，无需服务器或联网。先单步观看候选人、规则判断、余额更新；运行后比较宽度与零余额跳过数。输入身份编号，观察其在排序图中的位置改变。切换“28个状态”，点击三角图节点核对(甲,乙,丙)，单步看真实状态边；运行累积状态访问频数。

“重新开始”保留参数种子并回到初态；“重置实验”恢复默认。批量尝试的计数包括零余额跳过和自转账；动画帧不计为尝试。打开知识手册暂停，关闭后手动继续。

## 数学与数据边界
每次均匀独立选择付款人和收款人，允许同人。自转账统一记为无变化；非自转账中若禁止负债且付款人为0，跳过且不重新抽样。两种规则始终消耗同样随机数。总额及均值守恒。

非负模型固定总额M、人数N时，指定规则的平稳分布对所有非负整数余额向量均匀。单人余额k的精确概率为C(M-k+N-2,N-2)/C(M+N-1,N-1)。3人6单位共有28状态，甲余额0至6的状态数为7,6,5,4,3,2,1。大系统边际可近似几何分布，高平均余额下再作连续指数近似；曲线标为理论平稳参考，不伪称当前已平衡。
