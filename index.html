01

先预测，再动手

每个实验有默认例子。调整一个参数，再单步或播放，观察数据、数值与图形如何一起变化。

02

带着问题打开知识手册

每页右上角提供直觉、数学关系与精选阅读。阅读时暂停实验，关闭后从当前状态继续。

03

把整个实验带走

下载 ZIP 并完整解压，双击 index.html。每个主题可单独复制；实验和本地手册无需网络。

离线与兼容说明

外部阅读和 GitHub 链接需主动联网打开，不影响核心实验。实际验证范围与未测项见每个主题的 README.md；现代桌面 Chrome 和 Firefox 为本轮验收目标。
